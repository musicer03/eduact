# 高性价比基础教育指南

讲教师花几分钟课堂动作就能换回明显学习收益的做法，讲学生怎么复习才不白熬夜，讲家长怎么陪、怎么跟学校打交道，讲校长手里那点人财物先投给什么。也讲哪些流行做法其实是迷思——按学习风格分组、右脑开发、糖让孩子多动、练满一万小时。<br>
**84 条建议**，每条写明给谁、花掉什么、换回什么、证据有多硬、什么时候该停。来源只引期刊论文与 EEF 等官方证据库，每条都做了**支持与反方向的双向检索**——查不到反方证据，也是一种需要留痕的结论。

不用全做：这是按证据强度和性价比排好的备选单，不是任务清单——挑走一两条就算数。书里的证据主要来自国际研究，"本土适配"是按中职场景做的转译，不是本土验证；政策类内容以教育部及地方现行文件为准。发现写错了，欢迎[提 issue](https://github.com/musicer03/eduact/issues)。

## 怎么读

- **不用全做**：每篇内按证据强度×成本×见效速度排序，从每篇前几条看起，挑得动的先做。只想读 10 条的话，[总目录](book/总目录.md)里有快速上手清单和各身份的阅读路线。
- **想让 AI 帮你查**：仓库里带了一个 skill（[skills/eduact-guide](skills/eduact-guide/)），Claude Code 和 Codex 都能装。装上以后直接问「提问没人理怎么办」「该不该按成绩排座位」，它先把相关条目从正文里查出来，再按证据等级和成本排序回答，并注明出自第几篇第几条。查不到就说查不到，不自己编数字。装法见[那个目录的说明](skills/eduact-guide/README.md)。
- **收益分四维记账**：学业、动机、幸福感、公平各算各的，不折算——一条可以学业大赚、幸福感持平（如提取练习），也可以学业无效应、行为端大赚（如高频家校短信）。
- **看懂数字**：效应量、额外月数、95% CI 这些词，见[附录二](book/附录-证据分级与检索来源.md)的速查表。

每条建议都有**争议/反方证据**一栏和**停止信号**一栏——告诉你证据的边界，也告诉你什么时候该收手。这是这本书和一般"干货清单"最大的区别。

## 证据分级

| 等级 | 含义 |
| --- | --- |
| A | 元分析（多项研究合并计算）或随机对照试验（RCT），且报告了效应量 |
| B | 准实验、高质量综述，或单项研究支撑 |
| C | 实践共识，没有直接的研究文献（逐条注明） |

全书 84 条中 A 级 27 条（含 A− 1 条）、B 级 55 条（含 B− 2 条）、C 级 2 条。**每一条都做了支持与反方向的双向检索**，反方证据落在正文"争议/反方证据"栏；证据立不住或与中国国情不符的候选条目不静默删除，全部移入[附录一](book/附录-经审查未收录.md)并附完整理由（3 条，含因"学术暑期学校"制度在中国不存在而淘汰的寒暑假项目条目）。

几条诚实声明：

- **A 级只说明"有具体数字、出处可核"，不说明这个数字一定是因果。** 教学型领导的早期效应近年估计明显缩水，条目照收，但标注"相关非因果"；
- **"额外月数"只用 EEF 口径**，不与其他换算混用；
- 迷思篇每条都专门检索了"为迷思辩护"的文献——留级条目因此从"有害论"校准为"无效论"，测验收缩为"低风险自测是学习工具，不是评价武器"。
