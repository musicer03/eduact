# 高性价比基础教育指南

> 84 条"证据立得住、成本扛得住、中职用得上"的基础教育行动建议，附完整的证据审查流水线。

面向一线教师、学生、家长与学校管理者。每条建议都有明确的证据等级、成本、见效周期、争议反方证据与停止信号——告诉你**怎么做**，也告诉你**什么时候该停**。

## 这本书的特别之处

- **双向检索纪律**：每条建议不仅检索支持证据，还专门检索反方证据；迷思篇每条都为迷思本身检索了"辩护侧"文献。查不到反方证据，也是一种需要留痕的结论。
- **淘汰显性**：证据立不住的候选条目不静默删除，全部移入附录并附完整理由（见 `book/附录-经审查未收录.md`）。
- **诚实标注**：效应缩水、机制存疑、证据降级，都在正文里写明。例如：教学型领导效应近年估计明显缩水（仍收录，但标注"相关非因果"）；教师成长目标教师版查不到因果证据，诚实地降为 C 级。
- **中职适配**：全部条目按中职学校场景做了本土转译（分层辅导、实训管理、课后服务、职教政策锚点）。

## 方法论

1. **先有候选框架**：证据侧扫描（EEF Toolkit、元分析库、一手文献）提出候选清单；
2. **逐条证据审查**：支持 + 反方向双向检索，一手文献为准，多源交叉一致；
3. **修改 / 淘汰 / 加入**：证据不足的缩窄重定位或显性淘汰（入附录），立得住的展开成条目；
4. **核查轮消化**：每轮批量展开后专门做引用复核，凭记忆标注一律降为"待核"。

证据分级：**A** = 元分析/RCT 且有效应量；**B** = 准实验/高质量综述；**C** = 实践共识（须注明）。效应量→"额外月数"换算只用 EEF 口径。
