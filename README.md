# 高性价比基础教育指南

讲教师花几分钟课堂动作就能换回明显学习收益的做法，讲学生怎么复习才不白熬夜，讲家长怎么陪、怎么跟学校打交道，讲校长手里那点人财物先投给什么。也讲哪些流行做法其实是迷思——按学习风格分组、右脑开发、糖让孩子多动、练满一万小时。<br>
**84 条建议**，每条写明给谁、花掉什么、换回什么、证据有多硬、什么时候该停。来源只引期刊论文与 EEF 等官方证据库，每条都做了**支持与反方向的双向检索**——查不到反方证据，也是一种需要留痕的结论。

不用全做：这是按证据强度和性价比排好的备选单，不是任务清单——挑走一两条就算数。书里的证据主要来自国际研究，"本土适配"是按中职场景做的转译，不是本土验证；政策类内容以教育部及地方现行文件为准。发现写错了，欢迎[提 issue](https://github.com/musicer03/eduact/issues)。

## 怎么读

- **不用全做**：每篇内的条目按证据强度×成本×见效速度排序，从每篇前几条开始看就行。挑得动的先做，剩下的需要时回来查。
- **按身份走**：[总目录](book/总目录.md)里有阅读路线图——教师、学生、家长、管理者各自该读哪几篇、迷思篇哪些条目当自查用。
- **只想看结论最硬的**：全书 A 级 27 条（元分析/RCT 且有效应量），从[教师篇](book/教师篇.md) T-04 课堂小测、[管理者篇](book/管理者篇.md) M-02 教师教练制开始。
- **想快速上手**：只读 10 条——S-01 提取练习 · S-02 间隔复习 · T-04 课堂小测 · T-07 分散练习 · T-10 可教的行为规则 · T-15 作业设计 · P-01 高质量陪伴性对话 · M-02 教师教练制 · M-05 高频家校信息 · X-06 重读划线迷思。
- **条目之间会互相指路**（"见 T-07"这种）：每处指路后面都写着指向什么，不翻过去也知道说的是哪条。
- **看不懂效应量**：查[文末术语表](#读懂数字术语表)。

### 每条建议长这样（真实条目节选）

```markdown
### M-05 高频家校信息推送（每周自动短信）

给谁：校长、学生发展中心（掌握家校信息平台的人）
成本：极低（依托现有家校平台近乎零边际成本）
见效周期：数周（出勤与作业完成先动，成绩以学期计）

怎么做：推缺勤提醒、缺交作业清单、学业预警三类具体事实；
        高频、自动、具体是三个硬条件；默认全员开通。

收益：22 所初中高中随机对照——课程挂科 −27%、课堂出勤 +12%
     （Bergman & Chan, 2021, JHR 56(1)）。
诚实边界：同类设计中标准化测验成绩无效应——本条改的是努力
         行为（交作业、出勤、挂科），不承诺提分。
证据等级：A（多项 RCT）
争议/反方：同款干预的隔周低频版 RCT 四个结局全无效应；
          26,000 人试验出勤降但成绩不升；自愿报名会筛掉
          最需要的家长；短信替代不了关系型家校工作。
出处：只引一手文献，附 DOI，标注哪一轮核查核的。
本土适配：中职场景=实习周报推送、实训出勤预警、宿舍晚归提醒。
停止信号：两个月家长打开率趋零→换内容颗粒度；班主任把推送
         当免责工具→明文规定不替代个别沟通。
```

每条都有**争议/反方证据**一栏和**停止信号**一栏——告诉你证据的边界，也告诉你什么时候该收手。这是这本书和一般"干货清单"最大的区别。

## 四个收益维度

这本书想帮你换回的不只是分数，一共四样，各算各的，不互相折算：

- **学业**：成绩、掌握度、留存
- **动机**：想不想学、信不信自己学得会
- **幸福感**：焦虑、归属、师生与亲子关系
- **公平**：弱势学生是否受益更多

每条建议的"收益"栏按这四维分开写。提分和提动机不在一把尺子上——一条可以学业大赚、幸福感持平（如提取练习），也可以学业无效应、行为端大赚（如上面的家校短信）。合在一起算总分，只会把话算糊。

## 证据分级

| 等级 | 含义 |
| --- | --- |
| A | 元分析（多项研究合并计算）或随机对照试验（RCT），且报告了效应量 |
| B | 准实验、高质量综述，或单项研究支撑 |
| C | 实践共识，没有直接的研究文献（逐条注明） |

全书 84 条中 A 级 27 条（含 A− 1 条）、B 级 55 条（含 B− 2 条）、C 级 2 条。**每一条都做了支持与反方向的双向检索**，反方证据落在正文"争议/反方证据"栏；证据立不住的候选条目不静默删除，全部移入[附录一](book/附录-经审查未收录.md)并附完整理由（2 条）。

几条诚实声明：

- **A 级只说明"有具体数字、出处可核"，不说明这个数字一定是因果。** 教学型领导的早期效应近年估计明显缩水，条目照收，但标注"相关非因果"；
- **"额外月数"只用 EEF 口径**（英国教育捐赠基金会 Toolkit 的"多进步 X 个月"），不与其他换算混用；
- 文献信息以本仓库开源时点的核查状态为准：19 份[核查记录](核查记录/)留有全部检索式；个别卷期页标"待核"者为转引级标注，不承载主张；
- 迷思篇每条都专门检索了"为迷思辩护"的文献——留级条目因此从"有害论"校准为"无效论"，测验收缩为"低风险自测是学习工具，不是评价武器"。查不到，也是一种需要留痕的结论。

## 读懂数字（术语表）

<details>
<summary>展开 8 条术语（效应量 d/g、额外月数、odds、95% CI、RCT……）</summary>

| 术语 | 意思 |
| --- | --- |
| d、g | 效应量，表示两组差距有多大：0.2 算小，0.5 中等，0.8 大。g 是 d 的小样本修正版，读法一样 |
| r | 相关系数，两件事一起变的紧密程度，−1 到 1：0.1 弱、0.3 中等、0.5 强 |
| 额外月数 | EEF Toolkit 的换算：做这件事相当于比不做多进步几个月。+4 月是"同一学期里比没做的学生多学出约 4 个月的量"，不是"提前 4 个月毕业" |
| odds+40% | 发生比提高四成。比"概率提高 40%"更难直读，但试验报告常用，读作"作业完成的相对可能性明显更高"即可 |
| 95% CI | 95% 置信区间，真实值很可能落在的范围。区间跨过 0（或 1）就说"无统计学意义"——两组差别可能只是碰巧 |
| RCT | 随机对照试验：抽签一样把人分组，一组做、一组不做，过后比差距。证明"是这件事起了作用"最有说服力的做法 |
| 元分析 | 把很多项研究的结果合起来重新算，得出一个总数字。也叫荟萃分析、meta 分析 |
| 发表偏倚 | 显著的结果更容易被发表，导致合并出的总效应偏大。看到元分析说"校正发表偏倚后效应缩水"，就是这事 |

</details>
